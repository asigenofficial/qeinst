# موقع معهد خبراء الجودة للتدريب (QEI)

نسخة مراجعة ومتكاملة من الموقع، تتكون من واجهة عربية متعددة الصفحات **HTML/CSS/JavaScript** وواجهة خلفية **Laravel REST API** مع قاعدة بيانات SQLite جاهزة، ويمكن تحويلها إلى MySQL/MariaDB عبر migrations وseeders المرفقة.

## أهم ما هو موجود في هذه النسخة

- 53 برنامجًا تدريبيًا فعليًا مطابقًا لقائمة الدورات الموردة، موزعة على 12 مجالًا تدريبيًا.
- صورة مختلفة لكل برنامج تدريبي، ومسار الصورة محفوظ في جدول `programs` ليسهل تغييره لاحقًا.
- بحث وفلترة موحدة حسب: المجال، المستوى، وأسلوب التنفيذ.
- أسلوبا تنفيذ فعليان في الواجهة: `حضوري` و`عن بُعد`. لا يوجد خيار وهمي `عن بُعد (مسجل)`.
- 20 عميلًا وشريكًا مع الشعارات المحدثة، ومن ضمنها شعار الجمعية السعودية للإعاقة السمعية المصحح.
- معرض صور وفيديو مربوط بقاعدة البيانات، مع نسخ الملفات في الواجهة العامة وLaravel public.
- محتوى مؤسسي ومقالات ونماذج أثر بدون بيانات تجريبية أو أرقام تسويقية غير موثقة.
- تسجيل دخول عبر Laravel Sanctum، وحماية رابط ملخص طلب التسجيل برمز وصول خاص.
- لا توجد مسارات API عامة لإعادة تعبئة قاعدة البيانات.
- لا تحتوي قاعدة البيانات المرفقة على مستخدمين أو تسجيلات أو رسائل أو طلبات تجريبية.

## متطلبات التشغيل الأساسية

- **لتشغيل الواجهة الأمامية (Frontend):**
  - [Node.js](https://nodejs.org/) (إصدار 18 فما فوق).
- **لتشغيل الواجهة الخلفية (Backend - Laravel API):**
  - [PHP](https://www.php.net/) (إصدار 8.1 فما فوق) مع تفعيل إضافات `pdo_sqlite` و `sqlite3`.
  - [Composer](https://getcomposer.org/) لإدارة حزم PHP.

## خطوات التشغيل محلياً

### 🟢 الطريقة الأولى: التشغيل السريع بنقرة واحدة (Windows)

يتوفر في المجلد الرئيسي ملف تشغيل تلقائي:
1. انقر نقراً مزدوجاً على الملف: **`START-QEI-SITE.bat`**
2. يقوم الملف تلقائياً بالتحقق من المتطلبات، تشغيل خادم الـ API للباك إند على المنفذ `8000`، وتشغيل خادم الواجهة الأمامية على المنفذ `8080`، ثم فتح الموقع في متصفحك تلقائياً.

---

### 💻 الطريقة الثانية: التشغيل اليدوي خطوة بخطوة

#### 1) تشغيل الواجهة الأمامية (Frontend)

من المجلد الرئيسي للمشروع:

```bash
# تثبيت الاعتماديات (اختياري عند أول تشغيل)
npm install

# بناء ملفات الـ CSS
npm run build:css

# تشغيل خادم الواجهة الأمامية
npm run dev
```

* سيعمل الموقع مباشرة على الرابط: **`http://127.0.0.1:8080`**
* يتصل الموقع تلقائياً بالواجهة الخلفية عند توفرها عبر: `http://127.0.0.1:8000/api/v1`

---

#### 2) تشغيل الواجهة الخلفية (Backend - Laravel API)

من المجلد الرئيسي، انتقل إلى مجلد `backend`:

```bash
# 1. الدخول لمجلد الباك إند
cd backend

# 2. تثبيت الحزم والمكتبات
composer install

# 3. إعداد ملف البيئة ومفتاح التطبيق (في حال لم يكن معداً مسبقاً)
cp .env.example .env
php artisan key:generate

# 4. بناء قاعدة البيانات والبيانات الأولية (اختياري، توجد قاعدة SQLite جاهزة ومرفقة)
php artisan migrate --seed

# 5. تشغيل خادم الـ API
php artisan serve --host=127.0.0.1 --port=8000
```

* سيعمل خادم الـ API على الرابط: **`http://127.0.0.1:8000`**

---

## النشر على الخادم

في الإنتاج يفضّل أن تكون الواجهة والـAPI على نفس النطاق. اجعل الخادم يقدم صفحات وأصول الواجهة، ووجّه `/api/*` إلى Laravel الموجود في `backend/public/index.php`، مع منع الوصول المباشر إلى مجلدات `backend/app`, `backend/database`, `backend/storage` وغيرها.

في ملف `backend/.env` للإنتاج استخدم على الأقل:

```env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://YOUR-DOMAIN
LOG_LEVEL=warning
```

ثم شغّل:

```bash
cd backend
php artisan config:cache
php artisan route:cache
```

إذا استخدمت MySQL/MariaDB، اضبط متغيرات `DB_*` في `.env` ثم نفّذ:

```bash
php artisan migrate --seed
```

لا يوجد dump SQL قديم معتمد في هذه النسخة؛ **المصدر الرسمي للبنية والبيانات هو migrations + seeders**.

## تعديل الدورات والصور لاحقًا

مصدر بيانات الدورات هو جدول `programs`. أهم الحقول:

- `title`: اسم البرنامج.
- `category_id`: المجال.
- `level`: `مبتدئ` أو `متوسط` أو `متقدم`.
- `image`: مسار صورة البرنامج، مثل `assets/images/programs/courses/course-001.jpeg`.
- `is_featured`: إظهار البرنامج ضمن البرامج المميزة.
- `is_active`: إظهار/إخفاء البرنامج.

المواعيد وأساليب التنفيذ موجودة في جدول `program_schedules`. الفلترة لا تعتمد على كلمات ثابتة في HTML؛ بل تقرأ بيانات البرامج والمواعيد من الـAPI.

إذا أردت تغيير صورة دورة، ضع الصورة الجديدة داخل `assets/images/programs/courses/` وحدّث قيمة `programs.image`، ثم ضع نسخة منها في `backend/public/assets/images/programs/courses/` إذا كان Laravel يخدم الأصول مباشرة.

راجع أيضًا: `docs/COURSE_IMAGE_MAPPING_AR.md`.

## منطق الفلاتر

- يمكن اختيار أكثر من قيمة داخل نفس المجموعة؛ القيم تعمل بمنطق **OR** داخل المجموعة.
- بين المجموعات المختلفة يعمل الفلتر بمنطق **AND**. مثال: `مجال القيادة` + `متقدم` + `حضوري` يعرض البرامج التي تحقق الشروط الثلاثة.
- حاليًا جميع البرامج الـ53 مرتبطة بموعد يحتوي `حضوري / عن بُعد`، لذلك اختيار حضوري وحده أو عن بُعد وحده سيعيد نفس المجموعة الحالية. عندما تعدّل موعد برنامج في `program_schedules` ليكون أسلوبًا واحدًا فقط، ستتغير نتيجة الفلتر تلقائيًا.
- البحث يشمل اسم البرنامج والوصف والمجال.

## العملاء والشركاء

بيانات الجهات موجودة في جدول `clients`، والواجهة تستخدم تسمية موحدة: **عملاؤنا وشركاؤنا**. التصنيفات الحالية: حكومي، خاص، غير ربحي.

## 🗄️ تشغيل وإدارة قاعدة البيانات (Database)

تعتمد هذه النسخة على قاعدة بيانات **SQLite** مجهزة مسبقاً، وتتميز بأنها **مضمنة وتعمل تلقائياً فور تشغيل خادم الباك إند** دون الحاجة إلى تثبيت أو تشغيل خوادم قواعد بيانات منفصلة (مثل MySQL).

### 📍 موقع ملف قاعدة البيانات:
* **المسار:** `backend/database/database.sqlite`

---

### ⚙️ أوامر إدارة قاعدة البيانات (من داخل مجلد `backend`):

```bash
# 1. الدخول لمجلد الباك إند
cd backend

# 2. فحص حالة الجداول والميجريشن للتأكد من جاهزيتها
php artisan migrate:status

# 3. إعادة بناء قاعدة البيانات من الصفر وتعبئة البيانات الرسمية (Fresh Migration & Seeding)
php artisan migrate:fresh --seed

# 4. إعادة تغذية البيانات فقط بدون مسح الجداول
php artisan db:seed
```

> 💡 **ملاحظة لنظام Windows (PowerShell):**  
> إذا ظهر لك خطأ `php is not recognized`، يمكنك تفعيل مسار PHP في الجلسة الحالية بتنفيذ:  
> `$env:Path = "C:\laragon\bin\php\php-8.3.30-Win32-vs16-x64;C:\laragon\bin\composer;" + $env:Path`

---

### 🔍 روابط فحص البيانات الحية عبر الـ API:

عند تشغيل خادم الباك إند على `http://127.0.0.1:8000`، يمكنك اختبار الاتصال واستعراض البيانات مباشرة من المتصفح:
* **البرامج التدريبية:** `http://127.0.0.1:8000/api/v1/programs`
* **المجالات والتصنيفات:** `http://127.0.0.1:8000/api/v1/categories`
* **العملاء والشركاء:** `http://127.0.0.1:8000/api/v1/clients`
* **معرض الصور:** `http://127.0.0.1:8000/api/v1/galleries`

---

### 👁️ استعراض وتعديل الجداول بصرياً (GUI):
1. **عبر محرر الأكواد (VS Code):** يمكنك تثبيت إضافة **SQLite Viewer** وفتح ملف `backend/database/database.sqlite` مباشرة.
2. **عبر برنامج خارجي:** استخدام برنامج مجاني مثل **[DB Browser for SQLite](https://sqlitebrowser.org/)**.

---

### 🐬 التحويل إلى MySQL (اختياري للإنتاج أو البيئات المتقدمة):
1. قم بتشغيل خدمة MySQL (مثلاً من خلال **Laragon** أو **XAMPP**).
2. أنشئ قاعدة بيانات جديدة باسم `qeinst`.
3. في ملف `backend/.env`، عدّل إعدادات الاتصال:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=qeinst
   DB_USERNAME=root
   DB_PASSWORD=
   ```
4. نفّذ الأمر التالي لبناء الجداول وتعبئة البيانات:
   ```bash
   php artisan migrate:fresh --seed
   ```

## إعادة بناء بيانات الموقع

`backend/database/seeders/DatabaseSeeder.php` يستدعي مصادر البيانات المراجعة التالية:

- `WebsiteCatalogSeeder.php`: المجالات، البرامج، المواعيد، العملاء والشركاء.
- `SiteContentSeeder.php`: الحلول المؤسسية ونماذج الأثر (الأخبار والمقالات محذوفة من النسخة النهائية).
- `GalleryMediaSeeder.php`: المعرض ووسائطه.

لا يقوم الـSeeder بإنشاء مستخدمين وهميين أو كلمات مرور أو تسجيلات تجريبية.

## فحص الجودة قبل النشر

من جذر المشروع:

```bash
npm run build:css
npm run check:css
npm run qa
```

يفحص `qa.py` روابط الأصول، IDs المكررة، JavaScript، PHP، قاعدة البيانات، صور البرامج والعملاء والمعرض، البيانات التجريبية، والمصطلحات الأساسية.

## ملاحظات أمنية

- التسجيلات الجديدة تولد رقم طلب ورمزًا سريًا منفصلًا لتحميل ملخص الطلب؛ لا يكفي معرفة رقم الطلب وحده.
- تسجيل الدخول يستخدم Laravel Sanctum token وليس رمزًا وهميًا.
- endpoints الإنشاء عليها Rate Limiting.
- لا تضع `.env` أو قاعدة البيانات في مسار عام على خادم الويب.
- غيّر إعدادات البيئة والإرسال والبريد والنسخ الاحتياطي بما يناسب خادم الإنتاج قبل الإطلاق.
