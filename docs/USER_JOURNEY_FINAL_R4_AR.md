# خريطة رحلة المستخدم — QEI R4

## 1. التسجيل في برنامج تدريبي جاهز
الرئيسية أو البرامج التدريبية → اختيار البرنامج → تفاصيل البرنامج → التسجيل → البيانات الشخصية → بيانات العمل → البرنامج/طريقة التنفيذ → المراجعة → نجاح الطلب.

## 2. طلب حل مؤسسي موجود
الرئيسية أو حلول المؤسسات → اختيار أي حل (بما فيه تحليل الاحتياج التدريبي) → صفحة تفاصيل الحل الموحدة → «اطلب هذا الحل لمؤسستك» → نموذج الطلب مرتبط تلقائيًا باسم الحل → الاحتياج والمتطلبات → المراجعة → الإرسال.

## 3. طلب برنامج خاص من الصفر
حلول المؤسسات → «اطلب برنامجًا مخصصًا» → صمم برنامجك التدريبي معنا → بيانات الجهة → الاحتياج التدريبي → المراجعة والإرسال.

## 4. تحليل الاحتياج التدريبي
أصبح مثل بقية الحلول المؤسسية: بطاقة الحل → صفحة تفاصيل الحل الموحدة → طلب الحل. صفحة training-needs.html القديمة أصبحت تحويلًا توافقياً فقط حتى لا تنكسر الروابط القديمة.

## 5. التواصل
تواصل معنا → إرسال الرسالة → الحفظ في contact_messages → ومع إعداد SMTP تصل نسخة إلى info@qeinst.com.
