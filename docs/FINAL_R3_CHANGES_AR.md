# QEI Final R3 — ملخص التعديلات

- حذف «الشهادات الاحترافية» من الفوتر في جميع الصفحات.
- إعادة تنظيم الفوتر للجوال والتابلت والكمبيوتر، مع تقليل الطول على الجوال باستخدام عمودين للروابط وجعل التواصل بعرض كامل.
- إعادة بناء صفحة «تحليل الاحتياج التدريبي» بأيقونات SVG وتدرج بصري واضح ومخرجات ومنهجية وأسئلة شائعة وCTA مباشر.
- جعل «تحليل الاحتياج التدريبي» متاحًا من الرئيسية، صفحة حلول المؤسسات والفوتر، وليس من الفوتر فقط.
- جعل صفحات تفاصيل الحلول تعرض بيانات محلية فورية ثم تحدثها من API بدل انتظار قاعدة البيانات قبل ظهور المحتوى.
- تعديل زر «اطلب هذا الحل لمؤسستك» ليحمل الحل المختار إلى نموذج الطلب.
- نموذج «صمم برنامجك التدريبي معنا» أصبح يتكيف حسب نقطة الدخول:
  - من طلب برنامج خاص: يبقى نموذج برنامج مخصص.
  - من حل مؤسسي محدد: يتحول إلى «اطلب حلاً مؤسسياً لجهتك» ويعرض اسم الحل المختار.
- قاعدة البيانات تحفظ الآن `request_type` و`solution_slug` و`solution_title` داخل `corporate_requests`.
- إضافة Migration آمن لقواعد البيانات الموجودة مسبقًا.
- تحديث SQLite والـSeeder وملف SQL لتوحيد نفس المسار والحقول.
- إضافة خريطة رحلة المستخدم في `docs/USER_JOURNEY_FINAL_R3_AR.md`.

## عند رفع النسخة فوق قاعدة بيانات موجودة
بعد تثبيت مكتبات Laravel وتشغيل إعداد `.env`:

```bash
php artisan migrate
php artisan config:clear
```

أما قاعدة `database.sqlite` المرفقة في النسخة فهي محدثة بالفعل.
