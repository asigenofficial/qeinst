# خريطة رحلة المستخدم — QEI Final R3

## 1) الزائر الذي يريد برنامجًا تدريبيًا جاهزًا
الرئيسية → البرامج التدريبية → تفاصيل البرنامج → **سجّل الآن** → البيانات الشخصية → بيانات العمل → اختيار الموعد/التنفيذ → المراجعة → نجاح التسجيل.

إذا دخل المستخدم من زر **التسجيل** في الهيدر بدون اختيار برنامج، تبدأ صفحة التسجيل بقائمة برامج صغيرة ومنظمة ويختار البرنامج أولًا، ولا يتم افتراض برنامج سابق.

## 2) الجهة التي تعرف الحل المؤسسي الذي تحتاجه
الرئيسية أو الهيدر → **حلول المؤسسات** → اختيار حل مؤسسي → صفحة تفاصيل الحل → **اطلب هذا الحل لمؤسستك** → نموذج طلب مؤسسي مرتبط آليًا باسم الحل → بيانات الجهة → نطاق الحل ومتطلباته → المراجعة → إرسال الطلب → صفحة نجاح الطلب.

يحفظ النظام داخل `corporate_requests` نوع الطلب واسم/معرّف الحل المختار (`request_type`, `solution_slug`, `solution_title`) حتى يعرف فريق المعهد بالضبط أي حل طلبته الجهة.

## 3) الجهة التي تريد «تحليل الاحتياج التدريبي»
حلول المؤسسات → **تحليل الاحتياج التدريبي** → صفحة الخدمة التفصيلية السريعة → **اطلب تحليل الاحتياج لجهتك** → نموذج طلب مؤسسي مرتبط تلقائيًا بخدمة تحليل الاحتياج → المراجعة → الإرسال.

كما تبقى الخدمة متاحة من الفوتر تحت «حلول المؤسسات»، لكنها ليست محصورة بالفوتر.

## 4) الجهة التي لا تعرف الحل المناسب وتريد برنامجًا خاصًا
حلول المؤسسات → **طلب برنامج خاص** / «صمم برنامجك التدريبي معنا» → بيانات الجهة → وصف الاحتياج التدريبي → المراجعة → الإرسال.

هذه الرحلة تبقى مستقلة عن «طلب حل مؤسسي محدد». نفس النموذج التقني يستخدم، لكن العنوان والسياق والبيانات المحفوظة تختلف حسب نقطة الدخول.

## 5) الاستفسار العام
تواصل معنا → تعبئة الرسالة → تحفظ في `contact_messages` → عند إعداد SMTP ترسل نسخة إلى `info@qeinst.com` → يمكن للمعهد الرد على بريد المرسل.

## 6) من أين تظهر حلول المؤسسات؟
- الصفحة الرئيسية: بطاقات مختصرة.
- الهيدر: «حلول المؤسسات».
- صفحة الحلول المؤسسية: جميع الحلول.
- الفوتر: روابط مباشرة للحلول، تحليل الاحتياج، وطلب برنامج خاص.

## منطق التنقل المعتمد
- **معلومة عامة عن الحل** → صفحة تفاصيل الحل.
- **خدمة تحليل الاحتياج** → صفحة متخصصة مستقلة لأنها تحتوي منهجية ومخرجات وأسئلة شائعة.
- **طلب حل محدد** → نموذج مؤسسي يحمل اسم الحل آليًا.
- **طلب برنامج من الصفر** → نموذج «صمم برنامجك التدريبي معنا» بدون حل محدد مسبقًا.

هذا يمنع الالتباس السابق الذي كان يجعل زر «اطلب هذا الحل» يفتح صفحة تقول فقط «صمم برنامجك التدريبي معنا» بدون معرفة الحل الذي اختاره المستخدم.
