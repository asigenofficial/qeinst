# خريطة رحلة المستخدم النهائية — موقع QEI Institute

هذه الخريطة توضح المسار الكامل للمستخدم من أول فتح الموقع وحتى إكمال التسجيل أو إرسال طلب مؤسسة أو التواصل مع المعهد.

## 1. الدخول إلى الموقع

يصل المستخدم إلى الصفحة الرئيسية ويجد هيدر موحدًا يحتوي على:

- شعار QEI Institute.
- الرئيسية.
- عن المعهد.
- رؤيتنا ورسالتنا.
- البرامج التدريبية.
- حلول المؤسسات.
- عملاؤنا وشركاؤنا.
- تواصل معنا.
- قائمة «المزيد» للصفحات المساندة.
- زر «التسجيل».
- زر تغيير اللغة EN / العربية.

على الجوال والتابلت تتحول روابط التنقل إلى قائمة جانبية بخلفية معتمة، مع بقاء زر التسجيل واللغة واضحين في الهيدر.

## 2. مسار التسجيل من برنامج محدد

الصفحة الرئيسية أو صفحة البرامج
→ اختيار برنامج
→ فتح تفاصيل البرنامج
→ الضغط على «سجل الآن»
→ فتح صفحة التسجيل مع البرنامج المختار مسبقًا
→ يمكن للمستخدم تغيير البرنامج قبل إرسال الطلب
→ إدخال البيانات الشخصية
→ إدخال بيانات العمل عند الحاجة
→ اختيار طريقة التنفيذ/الخيارات المتاحة
→ مراجعة البيانات
→ إرسال الطلب
→ صفحة نجاح تحتوي على رقم الطلب.

مهم: لا يُعرض تاريخ ثابت على بطاقات البرامج. أي بيانات تشغيلية مرتبطة بالبرنامج تُدار من البيانات الفعلية وليست نصًا ثابتًا على البطاقات.

## 3. مسار التسجيل المباشر من الهيدر

الهيدر
→ الضغط على «التسجيل»
→ فتح صفحة التسجيل بدون برنامج محدد مسبقًا
→ اختيار البرنامج من قائمة مصنفة حسب المجال
→ لا يمكن الانتقال للخطوة التالية قبل اختيار برنامج
→ استكمال البيانات الشخصية
→ استكمال بقية خطوات التسجيل
→ مراجعة الطلب
→ إرسال الطلب
→ صفحة نجاح.

هذا يمنع ظهور برنامج قديم محفوظ في المتصفح عندما يدخل المستخدم من زر التسجيل العام.

## 4. تغيير اللغة

العربية:
- اتجاه الصفحة RTL من اليمين إلى اليسار.
- محاذاة الأرقام والعناصر الترتيبية بما يناسب القراءة العربية.

English:
- اتجاه الصفحة LTR من اليسار إلى اليمين.
- يعاد ترتيب عناصر الواجهة تلقائيًا بما يناسب الإنجليزية.

## 5. مسار حلول المؤسسات

الرئيسية أو الهيدر
→ حلول المؤسسات
→ اختيار الحل المناسب
→ عند طلب برنامج مخصص: «صمم برنامجك التدريبي معنا»
→ الخطوة 1: بيانات الجهة
→ الخطوة 2: الاحتياج التدريبي
→ الخطوة 3: المراجعة والإرسال
→ إرسال الطلب
→ صفحة نجاح الطلب.

زر «متابعة: الاحتياج التدريبي» ينقل فعليًا إلى الخطوة الثانية ولا يعيد نفس الشاشة.

## 6. مسار التواصل مع المعهد

الهيدر أو الفوتر
→ تواصل معنا
→ مشاهدة الهاتف والبريد وواتساب والموقع وساعات التواصل
→ مشاهدة الخريطة داخل الصفحة أو الضغط على «فتح في خرائط Google»
→ تعبئة نموذج الرسالة
→ إرسال.

المعالجة الخلفية:

المستخدم
→ POST /api/v1/contact
→ حفظ الرسالة في جدول contact_messages
→ محاولة إرسال نسخة إلى info@qeinst.com عبر SMTP
→ إذا تعطل البريد تبقى الرسالة محفوظة في قاعدة البيانات
→ عند نجاح البريد يمكن لفريق المعهد استخدام Reply للرد على بريد المرسل مباشرة.

## 7. معرض الصور

المستخدم
→ معرض الصور
→ تظهر الصور المحلية الاحتياطية مباشرة بدون انتظار شاشة تحميل طويلة
→ عند توفر API يتم تحديث المحتوى بالبيانات الحية بدون تعطيل العرض الأولي.

## 8. الصفحات التعريفية والسياسات

الهيدر/المزيد أو الفوتر
→ عن المعهد / الرؤية والرسالة / لماذا تختارنا / منهجية التدريب / الأثر المستدام / الأسئلة الشائعة / المركز القانوني.

في الصفحات العربية:
- أرقام بنود السياسات تظهر في جهة اليمين.
- النص RTL.
- البطاقات والنصوص لا تتجاوز حدودها على الجوال.
- الهيدر والفوتر موحدان على جميع الصفحات.

## 9. مخطط مختصر

```text
فتح الموقع
   |
   +--> استعراض البرامج --> برنامج محدد --> سجل الآن --> برنامج محدد مسبقًا --> التسجيل --> نجاح
   |
   +--> التسجيل من الهيدر --> اختيار برنامج إلزامي --> التسجيل --> نجاح
   |
   +--> حلول المؤسسات --> صمم برنامجك --> بيانات الجهة --> الاحتياج --> مراجعة --> نجاح
   |
   +--> تواصل معنا --> خريطة / هاتف / بريد / واتساب --> إرسال رسالة --> DB + Email
   |
   +--> الصفحات التعريفية والسياسات والمعرض
```

## 10. قواعد تجربة الاستخدام المعتمدة

- تصميم Responsive للجوال والتابلت والكمبيوتر.
- عدم وجود تمرير أفقي غير مقصود.
- العربية RTL والإنجليزية LTR.
- هيدر ثابت وموحد.
- فوتر موحد ومتوازن على كل الصفحات.
- الأرقام الإحصائية الظاهرة للمستخدم تستخدم الأرقام الغربية 0-9.
- الصور لا تدفع المحتوى خارج الشاشة.
- القوائم والنماذج قابلة للاستخدام باللمس على الشاشات الصغيرة.
