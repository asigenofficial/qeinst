# التدقيق النهائي — QEI

## الإصلاح الأخير: حلول المؤسسات

تم إصلاح حالة بقاء شعار QEI مكان بطاقات حلول المؤسسات. السبب كان تعارضًا زمنيًا بين تحميل `app.js` و`api-client.js` مع قيام `ui-runtime.js` بإخفاء المحتوى الاحتياطي ووضع Loader. أصبح السلوك النهائي:

- البطاقات الست موجودة كـ fallback داخل HTML ولا يتم إخفاؤها أثناء انتظار API.
- `api-client.js` محمّل صراحةً في صفحة حلول المؤسسات.
- `app.js` ينتظر جاهزية API بآلية آمنة بدل الاعتماد على توقيت 100ms.
- عند نجاح API يتم استبدال fallback ببيانات جدول `corporate_solutions`.
- عند فشل API تبقى البطاقات الست ظاهرة ولا يبقى شعار التحميل.
- الشبكة 3 × 2 على الشاشات المكتبية، ومتجاوبة على الأجهزة الأصغر.
- كل حل له صورة مستقلة موجودة في الواجهة وفي مرآة `backend/public`.

## قاعدة البيانات النهائية

SQLite: `backend/database/database.sqlite`

- 53 برنامجًا تدريبيًا نشطًا.
- 12 مجالًا تدريبيًا.
- 53 مسار صورة مختلفًا للدورات، وجميع الملفات موجودة.
- 20 عميلًا وشريكًا.
- 57 صورة في المعرض، بدون أي فيديو وبدون أوصاف صور.
- 6 حلول مؤسسية، وجميع صورها موجودة.
- 3 نماذج أثر/قصص نجاح غير رقمية تجريبية.
- لا يوجد جدول `articles` في النسخة النهائية.
- لا توجد بيانات مستخدمين أو تسجيلات أو رسائل أو طلبات تجريبية في قاعدة البيانات المرفقة.

## التعديلات السابقة المثبتة في هذه النسخة

- حذف الأخبار والمقالات من النسخة التشغيلية.
- إزالة ملفات الفيديو من الموقع والمعرض.
- إزالة وصف كل صورة في المعرض.
- صورة ثابتة للواجهة الرئيسية.
- عملاؤنا وشركاؤنا بتسمية موحدة مع 20 جهة وتصحيح شعار الجمعية السعودية للإعاقة السمعية.
- فلترة البرامج حسب المجال والمستوى وأسلوب التنفيذ والبحث.
- عدم استخدام خيار «عن بُعد (مسجل)» غير الموجود في البيانات.
- صور مستقلة للـ53 برنامجًا وربطها بقاعدة البيانات.
- إصلاح صور صفحة تفاصيل البرنامج وتحويل مسار صورة API إلى مسار الواجهة الصحيح.
- حلول المؤسسات: تفاصيل الحل تذهب لصفحة تفاصيل الحل، وطلب البرنامج الخاص إلى صفحة الطلب المخصص.
- قطاعات نخدمها: أزرار القطاعات لا تنقل المستخدم خارج الصفحة، وزر «استعراض جميع القطاعات» فقط هو رابط الانتقال.
- حذف الرسالة التوضيحية الزائدة أسفل «قطاعات نخدمها».
- حماية ملخص التسجيل برمز وصول، وإزالة مسارات Seed العامة القديمة.
