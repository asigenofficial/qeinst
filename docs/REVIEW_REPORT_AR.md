# تقرير مراجعة وتطوير موقع معهد خبراء الجودة للتدريب

تاريخ المراجعة: 8 أغسطس 2026

## 1. ملخص تنفيذي

تمت مراجعة المشروع كاملًا كواجهة أمامية وقاعدة بيانات وواجهة Laravel API، وليس فقط تعديل الشكل. النسخة الحالية تحتوي على **53 برنامجًا تدريبيًا، 12 مجالًا تدريبيًا، 20 عميلًا وشريكًا، و63 عنصر وسائط في المعرض**، مع ربط الصور والفلاتر والبحث بقاعدة البيانات.

## 2. البرامج التدريبية

- تمت مطابقة البرامج مع ملف الدورات المرفق، وإزالة سجلين مكررين كانا يرفعان العدد إلى 55 بدل 53.
- تم تصحيح الأخطاء الإملائية الظاهرة في عناوين الدورات بدون تغيير المعنى أو المدة.
- التوزيع الحالي للمستويات:
  - مبتدئ: 2 برنامجًا
  - متقدم: 27 برنامجًا
  - متوسط: 24 برنامجًا
- المجالات الحالية:
  - الجودة والتميز المؤسسي: 2 برنامجًا
  - الموارد البشرية والتطوير: 6 برنامجًا
  - المالية والمحاسبة: 1 برنامجًا
  - التخطيط والأداء المؤسسي: 11 برنامجًا
  - الحوكمة وإدارة المخاطر: 3 برنامجًا
  - القيادة والإدارة: 12 برنامجًا
  - العمليات والإجراءات: 3 برنامجًا
  - المشتريات والمخازن: 2 برنامجًا
  - العلاقات العامة والاتصال: 2 برنامجًا
  - خدمة العملاء وتجربة المستفيد: 7 برنامجًا
  - الأرشفة وإدارة الوثائق: 2 برنامجًا
  - العلاقات الدولية والدبلوماسية: 2 برنامجًا
- كل برنامج مرتبط بمجال، مستوى، وصف، مدة، صورة، وموعد تدريبي.

## 3. الصور

- تم إنشاء ربط **53 دورة = 53 مسار صورة مختلف**.
- الصور مأخوذة من وسائط المعهد الموجودة أصلًا داخل المشروع لتكون أقرب لطبيعة التدريب والجمهور السعودي.
- تم إصلاح مشكلة صور المعرض التي كانت موجودة فقط في Laravel ولم تكن موجودة في مسار الواجهة الأمامية.
- تمت إضافة نسخ وسائط المعرض في:
  - `assets/images/gallery/images`
  - `assets/images/gallery/video`
  - `backend/public/assets/images/gallery/...`
- يوجد fallback للصورة في حال فقد ملف مستقبلي.

## 4. البحث والفلترة

تم توحيد منطق عرض البرامج وإلغاء التعارض الذي كان موجودًا بين أكثر من Renderer في JavaScript.

الفلاتر الحالية:
- المجال.
- المستوى: مبتدئ / متوسط / متقدم.
- أسلوب التنفيذ: حضوري / عن بُعد.
- البحث النصي.

منطق الفلترة:
- أكثر من اختيار داخل نفس المجموعة = OR.
- بين المجموعات المختلفة = AND.
- الفلاتر تُحفظ في رابط الصفحة لتسهيل المشاركة والعودة لنفس النتيجة.

**مهم:** جميع المواعيد الحالية في قاعدة البيانات مكتوب فيها `حضوري / عن بُعد`، ولذلك فلتر حضوري أو عن بُعد سيعيد البرامج نفسها حاليًا. إذا عُدّل موعد برنامج ليكون حضوري فقط أو عن بُعد فقط، ستتغير نتيجة الفلتر تلقائيًا بدون تعديل JavaScript.

تم حذف الخيار غير الحقيقي `عن بُعد (مسجل)` الذي كان يضاف برمجيًا لكل دورة دون وجوده في قاعدة البيانات.

## 6. الرئيسية والتصميم

- توحيد تصميم بطاقات البرامج في الرئيسية وصفحة البرامج.
- تحسين أحجام الصور والمسافات والـtypography والاستجابة للشاشات.

- المؤشرات الظاهرة أصبحت مرتبطة ببيانات مثل عدد البرامج، المجالات، العملاء والشركاء، وأساليب التنفيذ.
- نماذج الأثر في الرئيسية أصبحت قابلة للتحميل من جدول `success_stories`.

## 8. التسجيل والأمان

- تم إغلاق مسارات API العامة التي كانت تسمح بإعادة seed للبيانات من رابط مباشر.
- تم تطبيق Rate Limiting على تسجيل الدخول، إنشاء الحساب، التسجيل، التواصل، وطلبات الشركات.
- تسجيل الدخول يستخدم Laravel Sanctum token.
- رابط تحميل ملخص التسجيل لم يعد يعتمد على رقم الطلب وحده؛ يتم إنشاء رمز وصول عشوائي خاص بكل طلب ويُخزن كـ SHA-256 hash.
- لا يتم قبول schedule لا يتبع البرنامج المحدد.
- تم تحسين التحقق من الهوية والبريد والجوال.
- تم تنظيف المستخدمين وكلمات المرور التجريبية من قاعدة البيانات المرفقة.

## 9. أخطاء بنيوية تم إصلاحها

- Renderer مكرر للدورات في JavaScript.
- IDs مكررة في نافذة التسجيل/الدخول داخل صفحة تقويم البرامج.
- مسارات صور المعرض غير الموجودة في الواجهة الأمامية.
- API البرامج لم يكن يعيد التصنيف المطلوب لتشغيل فلتر المجال.
- أزرار التسجيل في تفاصيل البرنامج كانت تستخدم معرفًا ثابتًا بدل البرنامج الفعلي.
- اختيار موعد التسجيل كان يرجع لأول برنامج بدل البرنامج المختار من الرابط.
- روابط/تعليمات نشر قديمة تعتمد على ملفات لم تعد موجودة.
- إزالة مسارات seed العامة وميدلوير تهيئة قاعدة البيانات أثناء الطلب.

## 11. فحص الجودة

يوجد سكربت `tools/qa.py` لفحص:
- روابط الصور والأصول المحلية.
- IDs المكررة في HTML.
- تركيب JavaScript.
- تركيب PHP.
- عدد البرامج والمجالات والعملاء.
- وجود صورة كل دورة في الواجهة وLaravel public.
- وسائط المعرض.
- عدم وجود بيانات تجريبية في الجداول التشغيلية.
- شعار الجمعية السعودية للإعاقة السمعية.
- عدم عودة خيار `عن بُعد (مسجل)`.
- عدم عودة المصطلحات القديمة للعملاء/الاعتمادات.

أوامر الفحص:
```bash
npm run build:css
npm run check:css
npm run qa
```

## 12. ما يحتاج إعدادًا عند النشر الفعلي

هذه النسخة تنظف وتجهز الكود والبيانات، لكن خادم الإنتاج نفسه يحتاج:
- ضبط `APP_URL` والدومين الحقيقي.
- `APP_ENV=production` و`APP_DEBUG=false`.
- إعداد البريد SMTP إن كان مطلوبًا.
- نسخ احتياطي دوري لقاعدة البيانات وملفات الرفع.
- توجيه `/api/*` إلى Laravel بشكل صحيح.
- SSL/HTTPS.
- حماية مجلدات Laravel غير العامة من الوصول المباشر.
